# Decisões arquiteturais

Registre mudanças relevantes à arquitetura com contexto, alternativas, escolha, consequências, responsável e status. Não apresente hipótese como decisão aprovada sem indicar quem decidiu.

Use o [modelo](template-adr.md) e arquivos como `0001-titulo.md`. A arquitetura inicial está em [planejamento](../../planejamento/03-arquitetura-e-tecnologias.md).
